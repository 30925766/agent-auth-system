# 代理商认证查询系统

一个基于 Flask、SQLite/MySQL 和 Bootstrap 的代理商授权查询系统，包含用户查询页、管理员后台和代理商独立后台。系统支持代理商授权信息查询、脱敏展示、头像管理、代理登录、操作权限控制、操作日志和站点文案配置。

本文档对应当前版本：**v1.2.0**，最后更新：**2026-10-24**。

## 功能总览

### 用户查询页

- 支持使用微信号或手机号查询代理商授权状态。
- 支持后台开关查询验证码。
- 查询结果可按后台配置显示或隐藏代理昵称、代理编号、脱敏微信号、脱敏手机号和授权时间。
- “授权时间”表示开始授权日期，不表示到期日期。
- 查询结果展示代理商头像、官方认证标识和自定义提示文案。
- “查看已授权代理人员”弹窗展示所有已启用代理商，按后台设置顺序排列，并展示头像及脱敏联系方式。
- 点击“联系官方客服”会复制后台设置的客服微信号，并在居中弹窗中展示复制结果和微信号。
- “返回网站”按钮跳转到后台自定义的链接。
- 提示、确认和客服复制弹窗采用统一的居中白色圆角样式。

### 管理员后台

管理员入口：`/admin/login`

- **控制台**：查看系统概况。
- **代理商管理**：新增、编辑、启用/禁用、删除代理商，支持搜索和筛选。
- **头像管理**：上传 JPG、PNG、WEBP、GIF 格式头像，最大 6MB；系统自动缩小并转换为 JPG。
- **代理登录配置**：为代理设置独立登录账号和密码，并控制是否允许登录。
- **排序管理**：设置代理商列表顺序，支持上移、下移、置顶；首页授权人员列表使用该排序。
- **批量操作**：批量启用或禁用代理商。
- **系统设置**：编辑网站名称、首页标题、充值提示、财产安全提示、客服微信号、返回网站链接和查询结果文案。
- **查询配置**：开关代理昵称、代理编号、微信号、手机号、授权时间等前端字段。
- **验证码设置**：关闭后首页不显示验证码，查询接口也不要求验证码。
- **操作日志**：记录后台登录、退出、新增代理、修改代理信息、启用/禁用、删除、排序及系统设置修改等操作。
- **日志检索**：支持搜索操作者、操作、对象、详情、IP 地址和时间，支持时间范围及日志类型筛选。
- **修改密码**：管理员可通过右上角账号菜单修改密码。

系统设置、查询配置和操作日志仅管理员可访问。

### 代理商后台

代理入口：`/agent/login`

代理账号必须由管理员创建，并开启“允许代理登录授权系统”、设置登录账号和密码后方可登录。

- 代理只能访问自己的控制台和代理商管理页面。
- 代理只能查看、编辑、禁用和删除自己创建的代理账号。
- 代理不能查看系统设置、查询配置和操作日志。
- 管理员可以查看和管理全部代理账号。

管理员与代理入口相互独立：管理员使用 `/admin/login`，代理使用 `/agent/login`。

## 环境要求

- Python 3.8 或更高版本，推荐 Python 3.12。
- Windows、Linux 或 macOS。
- 默认使用 SQLite，不需要单独安装数据库服务。
- 可选 MySQL 8.0 及以上版本。
- 生产环境建议使用 HTTPS、Nginx 和 Gunicorn。

## 本地安装与启动

### Windows

在项目根目录双击运行 `start.bat`。脚本会检查 Python、创建 `.venv`、安装依赖、初始化数据库，然后启动服务。

### Linux/macOS

```bash
chmod +x start.sh
./start.sh
```

也可以手动安装和启动：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python init_db.py
python app.py
```

默认访问地址：

- 查询页：`http://127.0.0.1:5000/`
- 管理员登录：`http://127.0.0.1:5000/admin/login`
- 代理商登录：`http://127.0.0.1:5000/agent/login`

## 默认管理员账号

首次初始化数据库时默认创建：

- 用户名：`admin`
- 密码：`admin888`

首次登录后请立即从右上角账号菜单修改默认密码。

## 数据库

默认 SQLite 数据库文件为项目根目录的 `agent_auth_system.db`。

如使用 MySQL，设置环境变量：

```text
DATABASE_URL=mysql+pymysql://用户名:密码@127.0.0.1:3306/agent_auth_system
```

也可以在 `config.py` 中配置。应用启动和初始化时会兼容创建站点设置表、操作日志表，并补充代理排序、代理登录及账号关联字段。升级时保留服务器当前数据库，不要用本地数据库覆盖。

## 宝塔部署

### 上传与依赖

将项目上传到宝塔网站目录，例如 `/www/wwwroot/agent-auth-system`。建议在宝塔 Python 项目管理器中选择 Python 3.9.25 或更高版本。

```bash
cd /www/wwwroot/agent-auth-system
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python init_db.py
```

### Python 项目配置

- 项目目录：`/www/wwwroot/agent-auth-system`
- 启动文件：`app.py`
- 启动命令：`python app.py`（也可使用 Gunicorn）
- 监听端口：`5000`
- 绑定地址：`127.0.0.1`

### 域名与反向代理

在宝塔添加网站并绑定域名，然后设置反向代理到 `http://127.0.0.1:5000`。配置 HTTPS 后访问：

```text
https://你的域名/
https://你的域名/admin/login
https://你的域名/agent/login
```

### 环境变量

在宝塔 Python 项目环境变量中设置：

```text
SECRET_KEY=一段随机且足够长的密钥
PYTHONUTF8=1
```

生成随机密钥示例：

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

不要将生产密钥提交到公开代码仓库。

## 更新部署

1. 备份服务器数据库，以及 `static/uploads/avatars/` 头像目录。
2. 将更新包解压到项目根目录，按包内 `templates/`、`static/`、`routes/`、`utils/` 等目录结构覆盖文件。
3. 保留服务器数据库、头像和环境变量，不要用本地数据文件覆盖。
4. 重启宝塔 Python 项目或 Gunicorn 服务。
5. 浏览器强制刷新，并登录后台检查新增功能和设置项。

代码更新通常不需要删除数据库。若更新包附带专门迁移说明，应按该更新包说明操作。

## 站点设置说明

后台“系统设置”可自定义：

- 网站名称、首页标题、充值提示、财产安全提示。
- 官方客服微信号：影响复制内容和客服弹窗显示。
- 返回网站链接：首页“返回网站”按钮的目标地址，必须使用完整的 `http://` 或 `https://` 链接。
- 认证通过标题、官方认证文字、认证提示内容。
- 代理昵称、代理编号、微信号、手机号和授权时间的字段名称。
- 查询验证码开关。

后台“查询配置”控制上述代理信息字段是否展示。关闭某字段后，该字段不会出现在查询结果和已授权代理人员展示中。

代理头像存放在 `static/uploads/avatars/`，备份和迁移服务器时需一并保留。

## 安全与备份建议

1. 修改默认管理员密码和默认 `SECRET_KEY`。
2. 生产环境启用 HTTPS。
3. 不要公开数据库、头像、日志和密钥文件。
4. 定期备份数据库与 `static/uploads/avatars/`。
5. 使用宝塔进程管理或 Gunicorn 运行生产服务，不要依赖开发服务器承载高并发。

## 常见问题

### 后台看不到新设置项

确认更新文件覆盖到了当前 Python 项目的实际运行目录，重点检查 `templates/admin/settings.html` 和 `utils/site_settings.py`，随后重启服务并刷新浏览器。

### 首页仍显示旧内容或旧弹窗

重启后端并强制刷新浏览器缓存，确认 `templates/index.html`、`templates/base.html`、`templates/partials/` 及 `static/js/`、`static/css/` 中的相关文件已更新。

### 返回网站按钮无效

在后台系统设置中检查返回链接是否为完整的 `http://` 或 `https://` 地址，保存后刷新首页。

### 验证码不显示

检查系统设置的验证码开关，并确认依赖安装成功。

### 代理无法登录

确认代理状态已启用、允许登录开关已打开、登录账号和密码已设置，且代理记录未删除。

### 502、503 或 504

检查宝塔 Python 项目进程、5000 端口监听状态、反向代理目标，以及 Python 和 Nginx 错误日志。

## Gunicorn 示例

安装并启动：

```bash
pip install gunicorn
gunicorn --workers 2 --bind 127.0.0.1:5000 app:app
```

宝塔或 Nginx 反向代理目标：`http://127.0.0.1:5000`。
